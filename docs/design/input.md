# 컴포넌트 명세서: Input 필드 클러스터

## 1. 목적 & 의도

* 사용자가 모임의 핵심 조건인 [장소, 날짜, 인원수]를 오타 없이 쉽고 빠르게 입력하도록 돕습니다.
* 텍스트 직접 입력 외에도 앞서 명세한 최근 검색어(Chips) 클릭 시 값이 자동 바인딩되는 인터랙션을 지원하여 모바일 환경에서의 입력 허들을 최소화합니다.

---

## 2. 레이아웃 & 정렬 구조

* **전체 구조:** 상하 배치 구조(`space-y-md`)로 결합된 양식 클러스터입니다.
* **1열 (상단):** '모임 장소' 필드가 가로 전체 너비(`w-full`)를 차지합니다.
* **2열 (하단 그리드):** '날짜'와 '전체 인원수' 필드가 50:50 비율의 2열 그리드(`grid grid-cols-2 gap-md`)로 병렬 배치되어 세로 스크롤을 줄입니다.

### 공통 스타일 속성

* **배경 및 형태:** 연한 회색 배경(`bg-surface-container-low`), 높이 `h-14`, 모서리 라운딩(`rounded-lg`), 보더 없음(`border-none`).
* **여백:** 아이콘 영역 확보를 위한 좌측 패딩 `pl-12`, 우측 패딩 `pr-4`.

## 4. 인터랙션 및 상태 위계 (UX)

### ① 포커스(Focus) 마이크로 인터랙션 (Script 반영)

* **Default 상태:** 아이콘 색상 회색(`#5e5e5e`), 테두리 없음.
* **Focus 상태:** 입력 필드 클릭 시 테두리에 두꺼운 블랙 라인 생성(`focus:ring-2 focus:ring-primary`). 좌측 아이콘 색상이 실시간으로 검은색(`#000000`)으로 변경되어 현재 활성화된 필드를 명확히 인지시킴.
* **Blur 상태:** 포커스 이탈 시 다시 Default 상태로 부드럽게 복귀(`transition-all`).

### ② 데이터 바인딩 위계 (우선순위)

1. **외부 컴포넌트 연동 (최우선):** '최근 검색어' 칩 버튼 클릭 시, 스크립트에 의해 '모임 장소' 필드에 값이 자동 입력(`targetInput.value = chip.textContent`)된 후 즉시 포커스 자동 이동.
2. **직접 입력 (보조):** 모바일 키보드 활성화를 통한 수동 타이핑 입력. 인원수 필드는 숫자 패드(`type="number"`) 대응.
