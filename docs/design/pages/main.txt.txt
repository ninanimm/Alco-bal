# 피드 화면 - 모바일

## 목적 & 의도
탐색을 위해 [장소, 날짜, 인원수]라는 핵심 기본 정보를 직관적이고 빠르게 입력하도록 유도

## 레이아웃 구조
- Main : 2 row
모바일 타겟 중심의 스크롤 뷰(Searchable Select) for 지역
Serachable Select for 날짜
Text-Input for 인원
- Bottom Action Area): Button for '다음' (상)
- Bottom Nav Bar : 최하단에 고정 (fixed bottom-0)되어 주요 메뉴 간의 이동을 돕습니다 (모바일 화면 md:hidden 대응).

## 컴포넌트 구조
1. 기본 정보 입력 섹션 (Form Section)
 1-1. 모임 장소 입력창 (Text Input): * 좌측에 location_on 아이콘 배치.
 1-2. 포커스 시 아이콘 색상이 다크하게 변하는 인터랙션 포함.
 1-3. 최근 검색어 칩 클릭 시 해당 텍스트가 자동으로 바인딩됨.

2. 날짜 & 인원수 입력창 (Grid Input): * 1행 2열 구조로 좌측은 날짜(Text형, Placeholer: 오늘), 우측은 인원수(Number형, Placeholder: 4명)를 입력받음.

3. 최근 검색어 섹션 (Quick Suggestions)
텍스트 링크: 우측 상단에 '전체 삭제' 기능 배치.
칩 버튼 (Chips): '강남역', '홍대입구' 등 최근 검색어가 가로로 나열되며, 클릭 시 '모임 장소' 입력창에 자동 입력 후 포커스 이동 스크립트가 적용되어 있음.

4.  하단 고정 버튼 (CTA Button)
'다음 단계' 버튼: 라운드 형태의 버튼(상). 클릭 시 다음 프로세스로 진입을 유도하며, 터치 시 미세하게 크기가 줄어드는(active:scale-95) 피드백 제공.

## 위계 (행동 및 중요도) ----
화면 내에서 사용자의 시선과 행동을 유도하는 우선순위 위계입니다.

[최우선 행동: 1등급]  '다음 단계' 하단 고정 CTA 버튼 클릭
       ▲
[주요 행동: 2등급]    모임 장소, 날짜, 인원수 필드 직접 입력
       ▲
[보조 행동: 3등급]    최근 검색어 칩 클릭 또는 추천 핫플레이스 카드 선택
       ▲
[이동 행동: 4등급]    상단 뒤로가기 및 하단 탭바를 통한 메뉴 전환
Primary (1순위 - 핵심 전환): 화면 하단에 무조건 고정되어 있는 '다음 단계' 버튼입니다. 정보 입력이 완료되면 가장 먼저 손이 가도록 검은색 배색(bg-primary)과 그림자 효과로 가장 높은 시각적 위계를 가집니다.

Secondary (2순위 - 필수 입력): '모임 장소', '날짜', '인원수' 입력 폼입니다. 화면 상단에서 하단으로 자연스럽게 시선이 흐르도록 가장 큰 타이틀 바로 아래에 배치되어 있습니다.

Tertiary (3순위 - 입력 지원): 직접 타이핑하는 수고를 덜어주는 최근 검색어 칩과 추천 핫플레이스 카드입니다. 2순위 양식을 채우기 위한 '보조 도구' 역할을 합니다.
